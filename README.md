# Thailandia 2026

Web app statica per visualizzare un itinerario di viaggio.

## Fonte dati

L'app legge direttamente:

https://sheetdb.io/api/v1/jvs32otchwgus?sheet=Itinerario

Sono supportate le colonne:

- Giorno
- Ore
- Descrizione
- Note
- Link
